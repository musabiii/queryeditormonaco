Закоммить текущие изменения репозитория.

1. Посмотри `git status --short` и `git diff` (и `git diff --cached`). Если изменений нет — так и ответь, ничего не делай.
2. Не коммить выгрузки конфигураций (`zupfiles/`, `medicine/`, `univer/` и другие папки выгрузок XML), `data/`, `.env*` и прочие секреты. Если такие файлы видны в статусе — остановись и спроси.
3. `git add -A`, затем коммит. Сообщение **на русском**:
   - заголовок до ~70 символов — что сделано, без точки в конце;
   - пустая строка и тело из 1–4 строк — зачем и что важно, если изменение не тривиальное;
   - последней строкой, после пустой строки: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
   Передавай сообщение через heredoc: `git commit -q -F - <<'EOF' … EOF`.
4. Если аргумент — `push` (сейчас: «$ARGUMENTS»), запушь:
   `git -c credential.helper= -c 'credential.helper=!gh auth git-credential' push origin master`.
   Без аргумента не пушь.
5. Ответь одной-двумя строками по-русски: хеш и заголовок коммита, запушено или нет.
