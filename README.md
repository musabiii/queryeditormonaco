# Редактор запросов 1С

Веб-редактор текста запросов 1С:Предприятия 8 на Next.js и Monaco Editor.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Как устроено

- **Monaco без CDN.** Скрипт `scripts/copy-monaco.mjs` копирует сборку `monaco-editor/min/vs`
  в `public/monaco` (запускается на `postinstall`, `predev`, `prebuild`; папка в `.gitignore`).
  Интерфейс редактора — на русском (`src/lib/monaco-loader.ts`).
- **Язык `sdbl`** (`src/lib/query-language/`):
  - `vocabulary.ts` — ключевые слова, функции, типы, объекты метаданных, виртуальные таблицы
    в русском и английском написании;
  - `grammar.ts` — токенизатор Monarch и настройки языка (комментарии `//`, скобки, автозакрытие);
  - `themes.ts` — светлая тема в цветах конфигуратора и тёмная тема;
  - `lexer.ts` — лексер для разбора текста вне Monaco;
  - `batch.ts` — разбор пакета на запросы для панели «Структура запроса»;
  - `formatter.ts` — форматирование в стиле конструктора запросов (Shift+Alt+F).

- **ИИ-помощник** (`src/lib/ai/`, `src/components/ai/`, `src/app/api/ai/`): чат справа от редактора
  с быстрыми действиями и вставкой ответа в редактор. Провайдеры: Anthropic (Claude) — через
  `@anthropic-ai/sdk`; OpenAI, Google Gemini, DeepSeek, OpenRouter, Ollama и LM Studio — через
  OpenAI-совместимый API (`openai`). Запросы идут через маршруты `/api/ai/chat` и `/api/ai/models`:
  ключ хранится только в браузере (localStorage) и передаётся серверу вместе с запросом.
  Адреса облачных провайдеров зафиксированы на сервере; свой адрес можно указать только для
  Ollama и LM Studio. Если выкладываете редактор в общий доступ, учтите: сервер будет обращаться
  к указанным адресам локальных моделей от своего имени.

Подсветка учитывает контекст: после точки идёт имя поля (`Док.Ссылка`, `Т.Количество`),
после `КАК` — псевдоним или тип, функции выделяются только перед скобкой (`СУММА(...)`),
`ССЫЛКА` считается оператором, только если справа путь к метаданным.
