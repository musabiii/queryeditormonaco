# Редактор запросов 1С

Веб-редактор текста запросов 1С:Предприятия 8 на Next.js и Monaco Editor.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Запуск на сервере в Docker

Образ (standalone-сборка Next.js, `Dockerfile`) собирает GitHub Actions при каждом пуше в `master`
и публикует в `ghcr.io/musabiii/queryeditormonaco` — на сервере сборки нет, нужна только загрузка.
Контейнер `queryeditor` подключается к внешней сети `nginx-net`, порт наружу не публикуется —
к нему обращается nginx из своего контейнера:

```bash
docker network create nginx-net   # если сети ещё нет
docker compose pull && docker compose up -d
```

Аналитика на своём сервере — Яндекс Метрика: номер счётчика задаётся переменной
`YANDEX_METRIKA_ID` (например, в файле `.env` рядом с `docker-compose.yml`), пересобирать образ
не нужно — после изменения `docker compose up -d`. Вебвизор выключен: он записывал бы тексты
запросов из редактора. На Vercel работает Vercel Analytics.

Пакет в GitHub Container Registry по умолчанию приватный: либо сделайте его публичным
(страница пакета → Package settings → Change visibility), либо войдите на сервере
`docker login ghcr.io` с токеном, у которого есть право `read:packages`.

```nginx
location / {
    proxy_pass http://queryeditor:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

Ответы ИИ-помощника идут потоком; маршрут `/api/ai/chat` отдаёт `X-Accel-Buffering: no`, поэтому
nginx не копит их целиком. Запросы к провайдерам ИИ делает сервер — с сервера в РФ API OpenAI,
Anthropic и Google, скорее всего, недоступны.

## Как устроено

- **Monaco без CDN.** Скрипт `scripts/copy-monaco.mjs` копирует сборку `monaco-editor/min/vs`
  в `public/monaco` (запускается на `postinstall`, `predev`, `prebuild`; папка в `.gitignore`).
  Интерфейс редактора — на русском (`src/lib/monaco-loader.ts`).
- **Язык `sdbl`** (`src/lib/query-language/`):
  - `vocabulary.ts` — ключевые слова, функции, типы, объекты метаданных, виртуальные таблицы
    в русском и английском написании;
  - `grammar.ts` — токенизатор Monarch и настройки языка (комментарии `//`, скобки, автозакрытие);
  - `themes.ts` — темы Monaco, построенные из цветовых схем `src/lib/color-schemes.ts`;
  - `lexer.ts` — лексер для разбора текста вне Monaco;
  - `batch.ts` — разбор пакета на запросы для панели «Структура запроса»;
  - `formatter.ts` — форматирование в стиле конструктора запросов (Shift+Alt+F).

- **Цветовые схемы** (`src/lib/color-schemes.ts`): 1С (классическая), VS Code Light/Dark,
  GitHub Light/Dark, Solarized Light/Dark, Dracula, One Dark, Monokai, Nord, Tokyo Night.
  Схема задаёт цвета подсветки, редактора и интерфейса; новая схема — одна запись в этом файле.
- **Метаданные конфигурации** (`src/lib/metadata/`): кнопка «Конфигурации» загружает выгрузку
  конфигурации в XML (Конфигуратор → «Выгрузить конфигурацию в файлы»). Из выгрузки читаются только
  `Configuration.xml` и описания объектов верхнего уровня (`Catalogs/Имя.xml` и т.п.), разбор идёт
  в Web Worker собственным разборщиком XML (`xml.ts`), модель сохраняется в IndexedDB браузера —
  файлы никуда не отправляются. Выгрузка ЗУП 3.1 (≈2300 файлов, 65 МБ) разбирается за ~3 с
  в модель 5,2 МБ.
- **Встроенные типовые конфигурации** (`public/configurations/`): готовые сжатые модели, которые
  всегда доступны в списке «Конфигурации» и скачиваются при первом выборе. Сейчас это
  «Зарплата и управление персоналом» 3.1.20.97, «Медицина. Больница» 2.0.16.1
  и «1С:Университет ПРОФ» 2.2.15.20.
  Добавить или обновить (папку выгрузки — в `.gitignore`, в `globalIgnores` ESLint и в `exclude` `tsconfig.json`):

  ```bash
  npm run configuration:build -- <папка выгрузки> --slug zup
  ```

  Скрипт сохраняет `<slug>-<версия>.json.gz` и обновляет `manifest.json`; прежняя версия с тем же
  `slug` заменяется.
- **Автодополнение** (`src/lib/query-language/completion/`): объекты после `Справочник.`, виртуальные
  таблицы и табличные части, поля по псевдониму с переходом по ссылкам, поля временных таблиц
  и вложенных запросов, значения перечислений; без точки — псевдонимы, ключевые слова, функции.
- **Дерево конфигурации** (`src/components/metadata/ConfigurationTree.tsx`, `smart-insert.ts`):
  перетаскивание вставляет имя; двойной клик добавляет в запрос под курсором — реквизит в список
  `ВЫБРАТЬ`, его таблицу (если её ещё нет) и таблицу целиком — `ЛЕВОЕ СОЕДИНЕНИЕ` с условием
  по типам реквизитов (иначе `ИСТИНА`, выделено); без `ИЗ` таблица становится первым источником,
  вне запроса создаётся новый.
- **ИИ-помощник** (`src/lib/ai/`, `src/components/ai/`, `src/app/api/ai/`): чат справа от редактора
  с быстрыми действиями и вставкой ответа в редактор. Провайдеры: Anthropic (Claude) — через
  `@anthropic-ai/sdk`; OpenAI, Google Gemini, DeepSeek, OpenRouter, Ollama и LM Studio — через
  OpenAI-совместимый API (`openai`). Запросы идут через маршруты `/api/ai/chat` и `/api/ai/models`:
  ключ хранится только в браузере (localStorage) и передаётся серверу вместе с запросом.
  Галка «Реквизиты таблиц» добавляет к сообщению поля и типы таблиц конфигурации, которые есть
  в запросе (`table-structure.ts`), — модель не придумывает имена реквизитов; повторно описание
  уходит, только если изменилось.
  Адреса облачных провайдеров зафиксированы на сервере; свой адрес можно указать только для
  Ollama и LM Studio. Если выкладываете редактор в общий доступ, учтите: сервер будет обращаться
  к указанным адресам локальных моделей от своего имени.

Подсветка учитывает контекст: после точки идёт имя поля (`Док.Ссылка`, `Т.Количество`),
после `КАК` — псевдоним или тип, функции выделяются только перед скобкой (`СУММА(...)`),
`ССЫЛКА` считается оператором, только если справа путь к метаданным.
